# docs/ — planning notes, kept for the record

These files are the working notes used while building QC-Trace (handover, work
packages, session prompts, video script). They were written **before or during** the
work and are not updated afterwards, so some details are out of date: for example they
mention 30 tests, "zero model results" and an LLM-judge arm (G2) that was never built.

The submission is described by the top-level `README.md`, `SOP.md` and `HYPOTHESES.md`.
Where these notes disagree with them, the top-level files are correct. The notes are
kept because the git history and these plans show how the project was built, which the
hackathon asks entrants to disclose.
